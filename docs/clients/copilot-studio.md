# Microsoft Copilot Studio

Minimal setup information from [clients.json](../clients.json), verified 2026-10-23.

## Prerequisites

- Microsoft Copilot Studio configured for streamable-http.
- A remote Polarion MCP server URL or a local stdio installation, plus a PAT when required by the selected authentication mode.

## Setup

Transport: streamable-http. Authentication modes in the manifest: static-header, oauth-dcr, preregistered-client.

```text
In agent Tools, add Model Context Protocol with URL https://YOUR-SERVER/mcp; choose API key header Authorization, or OAuth 2.0 Dynamic discovery when server metadata supports it.
```
