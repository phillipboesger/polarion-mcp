A few things before you go

Questions? Start here.

Setup, permissions and updates, in one place.

Which setup do I need?

For a desktop or coding client, start with local npm / npx. Your client launches the server and holds the Polarion URL and PAT in private settings. To share a server, use Docker. For claude.ai or a ChatGPT connector, use the HTTPS URL of a team server with OAuth. Already have one? Select Remote URL in the picker. Custom GPT Actions uses the separate REST wrapper.

Is my data safe? Which permissions apply?

Polarion enforces the token owner’s permissions. Local stdio uses your configured PAT; remote MCP uses each caller’s PAT, directly or through the server’s OAuth login. The REST wrapper uses its deployment PAT for all callers. The server sends tool results back to your AI client, so your provider’s data handling and your organization’s policies still apply. Use HTTPS remotely, keep secrets out of Git, and grant only the access you need.

Can I use it in read-only mode?

Yes. Set MCP_READ_ONLY=1 in the server environment and restart or reconnect. It exposes only tools marked read-only and blocks writes. For write-enabled sessions, pass dry_run: true to a mutating REST tool to inspect its request without saving. A preview is not a saved draft or an approval lock.

Which Polarion versions work?

Live integration tests have passed on Polarion 2506 and 2606. The tools are generated from a Polarion OpenAPI definition; that does not guarantee every operation on every release. Your REST API configuration, available endpoints and permissions matter. Verify the operations you rely on against your own instance.

Which AI clients can I use?

Use a client that supports MCP stdio or Streamable HTTP: Claude Desktop, Claude Code, Cursor, VS Code, Codex, Gemini CLI and others have setup paths above. claude.ai and ChatGPT connectors use a hosted endpoint. Other providers can use any compatible MCP client, or the separate REST/OpenAPI wrapper. Account permissions and tool budgets vary; choose a subset of tools when needed.

How do I update?

For local npx, reconnect after refreshing the package. Run npx -y polarion-mcp@latest through your client, or pin a release for predictable updates. For Docker, pull the chosen release tag and recreate the container with the same configuration and stable OAuth secret. With a team URL, the administrator updates the server; refresh the client’s tool list or reconnect. Regenerating tools from OpenAPI is a maintainer task, not a required client update.
