polarion-mcp

An open-source Model Context Protocol server for the Polarion ALM REST API. Connect AI clients to Polarion through stdio or Streamable HTTP, with a separate REST wrapper for integrations using OpenAPI actions.

Quickstart

Connect a remote or local client

For a remote MCP client, use your server's MCP URL (for example, https://YOUR-SERVER/mcp) and authenticate with your Polarion personal access token (PAT). OAuth login is available when enabled by the server administrator. See the client setup guides.

For a local stdio client, set the Polarion REST API URL and PAT in its environment, then run:

API_BASE_URL=https://YOUR-POLARION/polarion/rest/v1 BEARER_TOKEN=YOUR_POLARION_PAT npx -y polarion-mcp

Polarion tools for AI clients

Tools are generated from the Polarion REST API definition.

Guarded operations

Guard selected risky changes and optionally limit access to read-only or allowlisted tools.

Dry run support

Preview supported guarded operations before applying a change.

Markdown rendering

Render supported Polarion content as Markdown for AI clients.

Toolsets

Select groups of tools to match the task and client.

REST wrapper

Use the reduced OpenAPI document for action clients.

Authentication overview

Use a PAT directly or sign in with OAuth

MCP clients can use a Polarion PAT directly as a bearer token, or use the server's OAuth login when enabled. OAuth lets users enter their PAT through the server login flow. The REST wrapper uses its configured server-side credentials and API key.

Read Authentication and security, configuration, and the individual client guides.
