Local · JSON

Local MCP configuration

Same format: Desktop · Cursor · Windsurf · JetBrains · Cline

  1. Open Claude Desktop Settings > Developer > Edit Config.
  2. Paste the snippet, merge with existing settings, and replace the Polarion URL and PAT.
  3. Save, fully quit and reopen Claude Desktop. Ask: “List the Polarion projects I can access.”
json
{
  "mcpServers": {
    "polarion": {
      "command": "npx",
      "args": ["-y", "polarion-mcp"],
      "env": {
        "API_BASE_URL": "https://YOUR-POLARION/polarion/rest/v1",
        "BEARER_TOKEN": "YOUR_POLARION_PAT"
      }
    }
  }
}

Node.js 22+ runs the published npm package on your computer. Replace the URL and PAT locally; keep credentials out of Git.
